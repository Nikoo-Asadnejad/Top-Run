# Top-Run Feature

This repository contains a clean implementation guide for the Subway Surfers Top-Run feature.

Top-Run is a weekly leaderboard where players compete with other players from the same **country** and similar **level range**. A player's **best score** determines their rank, tier, and position on the board.
